# 优淘 · YOUTAO (次世代赛博前沿电商平台)

> 汇聚未来智能装备、全天候机能服饰与寰宇风味的赛博朋克电商展示网站。适配全年龄段视力无障碍阅读标准。

## 🌟 核心特性
- **赛博朋克微光美学**：量子青蓝、星际深蓝与全息微光，兼具科技感与全人群视觉舒适度。
- **全年龄无障碍支持**：提供标准、大号、特大字号即时切换，以及一键护眼高对比度模式。
- **国际多币种切换**：即时支持人民币（¥ CNY）与美元（$ USD）汇率动态换算。
- **多维商品检索与分类**：支持多类目切换、搜索框即时模糊过滤、热门关键词与销量/价格排序。
- **完整模拟购买流程**：商品规格（SKU）选择弹窗、能量补给舱（抽屉购物车）、满减优惠自动计算与模拟出库结算。
